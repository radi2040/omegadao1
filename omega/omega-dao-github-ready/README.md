## Run locally

```bash
npm install
npm run dev
```

Then open:

```txt
http://localhost:3000/projekte/omega-dao
```

## Deploy

You can push this repository to GitHub and import it into Vercel.

## Important positioning

Omega DAO is framed as a long-term engineering and portfolio project, not as a finished company, token sale, investment product, political organization, or live DAO.
